LLM 답을 GitHub 코멘트로 올리는 봇은 흔히 답 끝에 `<sub>모델 · 토큰 · 비용</sub>` 같은 꼬리말을 단다.
`github-markdown` 이 줄 첫머리 태그를 통째로 벗겨 작은 글씨가 보통 글씨가 됐다. GitHub 렌더 API 는 `<p><sub>…</sub></p>` 로 그린다 — 태그
뒤에 글이 오는 줄은 HTML 블록이 아니다.

기대: GitHub 에서는 꼬리말 `<sub>` 가 남는다. 태그를 못 그리는 채널은 전처럼 벗긴다. 접어 두는
`<details><summary>` 는 아직 벗긴다(내용은 남는다, SPEC 4절). 같은 문서의 조사 앞 굵게
(`**「…」**가`)는 GitHub 에서 `<strong>`, 범위 물결표는 `\~`.
