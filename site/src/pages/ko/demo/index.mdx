# 데모

모든 데모는 npm 패키지의 WASM 빌드로 브라우저에서 실행됩니다. 서버는 쓰지 않습니다. 데모마다 아래에
코드가 있습니다.

- **[텔레그램 대 슬랙](/ko/demo/channels/)**: 에이전트 답 하나를 두 채널용으로 변환합니다. 화면에 보이는
  것이 채널로 나가는 텍스트 그대로입니다.
- **[스트리밍](/ko/demo/streaming/)**: 같은 답을 같은 토큰으로 잘라 react-markdown, Streamdown,
  Streamdown 앞에 둔 mdwire, mdwire React 훅에 동시에 흘려 보냅니다.
- **[정규화 전후](/ko/demo/repair/)**: 실제로 깨졌던 에이전트 출력과 mdwire 가 보내는 결과를 나란히
  놓습니다. 바뀐 부분을 모두 표시하고, 바뀐 횟수를 센 정규화 보고도 보여 줍니다.

입력은 [코퍼스](https://github.com/minjun0219/mdwire/tree/main/corpus/cases)에서 가져왔고, 모두 실제로
겪은 문제입니다. 입력을 직접 고쳐 봐도 됩니다.
