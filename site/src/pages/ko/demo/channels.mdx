# Telegram vs. Slack

에이전트 답변 하나를 두 채널용으로 변환합니다. 화면에 보이는 것이 채널로 나가는 텍스트 그대로입니다.
텔레그램에는 `parse_mode: "HTML"` 로, 슬랙에는 `markdown_text` 로 넘기는 본문입니다.

예시는 [테스트 케이스](https://github.com/minjun0219/mdwire/tree/main/corpus/cases)에서 가져왔고, 모두 실제로
겪은 문제입니다. 입력을 직접 고쳐 봐도 됩니다.

<div class="wide">
  <ChannelCompare client:only="react" lang="ko">
    <p slot="fallback">WASM 빌드를 불러오는 중…</p>

텔레그램은 태그를 받습니다. HTML 모드에는 헤딩도 표도 없어서 표는 고정폭 블록으로 나갑니다. 슬랙
`markdown_text` 는 표준 마크다운을 읽으므로 출력도 고친 뒤의 마크다운입니다. 어느
채널로 보내든 닫히지 않은 강조와 코드펜스는 먼저 닫습니다. 출력 아래의 숫자는 정규화가 고친 횟수와
채널에 맞춰 바꾼 횟수를 보여 줍니다.

<details class="code">
<summary>이 데모의 코드</summary>

```ts
import { renderWithReport } from "@minjun0219/mdwire";

for (const channel of ["telegram-html", "slack-markdown"]) {
  const out = renderWithReport(input, channel);
  out.parts;   // 보낼 텍스트. 길이 제한을 넘지 않으면 문자열 하나
  out.repairs; // closedEmphasis · closedFence · … · convertedMarker, 모두 열 가지
  out.free();  // 결과는 WASM 메모리에 있으므로 다 쓰면 해제
}
```

전체 컴포넌트: [`site/src/components/ChannelCompare.tsx`](https://github.com/minjun0219/mdwire/blob/main/site/src/components/ChannelCompare.tsx).
