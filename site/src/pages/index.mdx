# Send LLM Markdown to chat channels without it breaking

mdwire is **not a general-purpose Markdown converter.** It is a bridge: it takes the Markdown an
agent wrote and hands each channel the syntax that channel actually accepts — repaired, escaped,
and split within its length limit. Rendering is still the channel's job.

```
LLM markdown  →  normalize  →  render for channel  →  split safely  →  send
```

1. **Normalize.** Agent-written Markdown may not render correctly through a standard
   Markdown converter: unpaired `**`, emphasis that spans a line break in wrapped prose, unclosed
   code fences. Repair before rendering.
2. **Render.** Emit the syntax the channel accepts. Telegram HTML allows nine tags; Slack
   `markdown_text` takes standard Markdown directly.
3. **Split.** Respect the channel's limit and never cut through markup — including while
   streaming, where a chunk boundary must not land inside `**bold**`.

## Why another one

Three gaps in what exists today, each measured rather than assumed:

- **Broken input is the normal case.** In a sample of 60 agent-generated documents,
  44 contained emphasis spanning a line break. A regex-based converter mispaired those
  into *inverted* emphasis ranges, and the channel returned HTTP 200, so nothing caught it.
- **CJK is guessed at.** One converter pads emphasis with U+200B next to Korean text;
  another does not. Neither measured the channel. We did: Slack `markdown_text` follows
  CommonMark, so `_italic_` dies next to a Korean particle and `*italic*` lives. mdwire
  emits `*` and pads nothing.
- **Streaming has no answer.** Every converter is batch: parse the whole document, build an
  AST, render. When tokens arrive incrementally, markup splits across chunk boundaries.

## Targets

Telegram HTML, Slack `markdown_text`, GitHub comments (GFM), Notion pages, plain
text, and HTML for the browser — from a Rust core, a CLI, an npm package (WASM), and a Go port held to the same
corpus.

## Install

```sh
npm install @minjun0219/mdwire     # npm — bundlers, Node, Bun
cargo add mdwire-core              # Rust library (`use mdwire::…`)
cargo install mdwire-cli           # the `mdwire` CLI
go get github.com/minjun0219/mdwire/go@latest
```

The [docs](/docs/) cover the shared concepts and the API of each: [npm](/docs/npm/),
[Rust](/docs/rust/), [Go](/docs/go/) and the [CLI](/docs/cli/).
